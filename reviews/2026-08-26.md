## Recommended changes

### 13. `video-use` — edit raw footage with Claude Code
**Source:** @ty.prompts.ai, https://www.tiktok.com/@ty.prompts.ai/video/7673918918855003406
**Claim:** "You drop raw footage in a folder, tell Claude Code to edit it, and
it cuts the umms and the dead space, color grades every segment, and burns the
2 word uppercase captions you see on every viral clip." From the browser-use team.
**Verified:** **Yes** — `browser-use/video-use`, **21,411 stars**, described by
its own repo as "Edit videos with coding agents".
**Why it fits:** This is the closest match to the agency's actual output of
anything in either folder. Short-form social edits with burnt-in captions are
the deliverable, and the described workflow — footage in a folder, instruct the
agent — needs no new interface. It is also from the browser-use team, who have
a real track record, not an anonymous repo.
**Caveat:** unverified whether the caption/grade quality survives client work.
Trial it on one internal edit before it touches a client deliverable.

### 14. Revisit **HyperFrames** — you already trialled it
**Sources:** @ty.prompts.ai (above); @omgluka https://www.instagram.com/p/DZv8-rvkZ9E/
**Claim:** "HeyGen open-sourced it: you describe the video, your coding agent
writes the HTML, and it renders a real MP4, with 41k stars behind it."
**Verified:** **Yes** — `heygen-com/hyperframes`, **42,789 stars**, "Write HTML.
Render video. Built for agents."
**Why it fits:** This is the **third independent reference** to HyperFrames
across both platforms — and you have already used it. a local trial folder
contains real compositions (internal test projects), last
touched **5 Aug**, three weeks ago. So the recommendation is not "try this";
it is that the project has moved since you set it down, and two separate
creators independently landed on it.

Note it solves a **different** problem from `video-use`: HyperFrames generates
motion graphics from HTML, `video-use` edits existing footage. They complement
rather than compete — HyperFrames for titles/animated inserts, `video-use` for
the talking-head cut.

**Suggested:** decide deliberately whether `hyperframes-test` becomes a real
internal tool or gets deleted. Right now it is a stalled experiment with real project names in it.
