### 1. OpenSEO — self-hosted SEO tool with native Claude Code MCP plugin

**Claim:** Open-source alternative to Semrush ($139/mo) and Ahrefs ($129/mo).
Pulls competitor keywords, backlinks, and ranking pages; on your own site it
tracks rankings, crawls technical issues, reads Search Console, and shows
whether ChatGPT/Google AI Overviews mention your brand. Connects to "Claude or
Codex" as an agent that can pull numbers, compare opportunities, and cluster
keywords. Hosted tier starts at $10/month; self-hostable.
**Verified:** yes — GitHub API confirms `every-app/open-seo`: 15,709 stars,
MIT license, created 2026-02-27, pushed 2026-08-24 (active), description
"Open source alternative to Semrush and Ahrefs" matches the caption verbatim.
Docs at openseo.so confirm a native Claude Code plugin: `/plugin marketplace
add every-app/open-seo` then `/plugin install openseo@openseo`, which installs
an MCP server (`https://app.openseo.so/mcp`) plus nine SEO agent skills
(keyword research, competitor analysis, clustering, link prospecting). Pricing
claim not independently verified (docs pages fetched didn't surface a pricing
table) — treat the $10/mo figure as caption-sourced, not doc-confirmed.
**Why it fits:** The business is an agency running SEO/content work for
clients — this is a specific, working, actively-maintained tool that plugs
directly into Claude Code via MCP rather than requiring a separate dashboard
login. Nothing equivalent exists in the current setup (`claude-seo`, already
in `skills.json` from 2026-08-28, is a technical-SEO *audit* skill with no
keyword/competitor/backlink data source behind it — this is complementary,
not a duplicate).
**Proposed action** (not applied):
```
/plugin marketplace add every-app/open-seo
/plugin install openseo@openseo
```
Requires a login to OpenSEO after install (`/mcp` to authenticate). Confirm
the actual pricing on openseo.so before committing to the hosted tier.

## Flagged — real tool, but the post's central claim is false

### 2. here.now — agent-hosted review pages (NOT a Vercel product)
**Source:** @mr.paidsocial, https://www.tiktok.com/@mr.paidsocial/video/7674101926191058190
**Claim:** Creator edits entire videos with Claude Code (motion graphics,
captions) and has it spin up a here.now page so they can watch the render and
leave a comment on individual timestamps instead of typing notes in chat;
Claude Code then reads the feedback and builds the next version. States
"here.now is made by Vercel and it has its own agent integration."
**Verified:** partially, and the headline claim is wrong. `here.now` is real
and does what's described mechanically — WebFetch of here.now and its docs
confirms it's zero-config static web hosting built for AI agents (publish a
file/site via HTTP API, get a live URL at `{slug}.here.now` in seconds), with
a GitHub org at `heredotnow/skill`. A web search independently confirms it's
served from **Cloudflare's** edge network, not Vercel, and no source —
official docs, third-party writeups, or the product's own X account — mentions
any Vercel affiliation. **The post's "made by Vercel" claim does not check
out.** The Vercel-adjacent naming and "agent integration" framing likely made
it sound like an official Vercel product; it isn't one.
**Why it's flagged instead of recommended:** The underlying technique is
genuinely good and net-new to your setup — the already-installed `video-use`
skill's review loop (`SKILL.md` at `~/Developer/video-use/SKILL.md`) is
chat-based "natural-language feedback" typed under a rendered preview, which
is exactly the friction this post describes. Swapping in a hosted
timestamped-comment page is a real upgrade to that step. But recommending a
tool on the strength of a false "backed by Vercel" claim would be recommending
it for the wrong reason — flagging it here so you can evaluate here.now (a
small, independent, free-tier service) on its own merits rather than on a
trust signal that isn't real.
**If you want to try it (not applied):** Point `video-use`'s "Iterate +
persist" step (`SKILL.md:100`) at here.now instead of a local preview — have
Claude Code publish the render + a comment UI to `{slug}.here.now`, collect
timestamped notes, then re-render. Check `heredotnow/skill` on GitHub for the
actual agent-skill contract before wiring anything in.
