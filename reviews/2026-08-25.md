### 10. Adopt three practices from Anthropic's own "Claude Code Guide for Startups" — `~/.claude/CLAUDE.md`
**Source:** @artificialintelligenceupdater, https://www.instagram.com/p/DcbthMGn_bu/
**Claim:** Caption says "Anthropic has released the Claude Code guide for startups"; on-screen frame is a
27-page PDF branded "Claude Code" with real Anthropic customer logos (Cognition, Harvey, Clay,
ClickHouse, Crosby, Heidi, Higgsfield) as featured case studies, split into four chapters. This reads as
genuine Anthropic content marketing — the branding and customer list match Anthropic's known case-study
roster — though I could not find an indexed public URL for the PDF itself to double-check wording.
**What the checklist frame actually says**, verbatim from the on-screen image:
- *"Use skills for on-demand procedural workflows... Use CLAUDE.md files in each subdirectory of your
  repo for coding conventions specific to that subdirectory that apply every time."*
- *"Use git worktrees to run a rebuild in an isolated copy of the repo while the current version stays
  untouched. This is what makes 'build it four times' cheap."*
- *"For non-trivial rewrites, start Claude Code in plan mode (/plan or Shift+Tab). Claude will explore the
  codebase and propose the rebuild approach before writing any code — you approve or redirect."*
- *"Hooks... can serve as hard gates. Use these when components of the work need to be deterministic."*
**Why it fits:** Your global CLAUDE.md is a single root file — none of your active projects use
subdirectory-level CLAUDE.md files for module-specific conventions, and there's no standing habit of
`/plan` before a non-trivial rewrite. You already have hooks wired (secret-guard, edit-lint, phase
boundaries) so "hooks as hard gates" is a validated pattern, not a new one — this just names the general
principle. Git worktrees are also already available to you as `isolation: 'worktree'` in the Workflow
tool, but nothing currently prompts you to reach for it before a risky rewrite.
**Proposed diff:**
```diff
 ## Working style

 - Act when you have enough to act. Don't re-ask decisions already made.
 - Make routine judgment calls yourself; ask only when two readings lead to materially different work.
 - Report what actually happened, including failures and skipped steps.
+
+## Non-trivial rewrites
+
+Before a rewrite that touches architecture (not a small fix), start Claude Code in plan mode
+(`/plan` or Shift+Tab) so the approach gets proposed and approved before code is written. For a
+risky rebuild, do it in an isolated git worktree so the current version stays untouched — "build it
+four times" is cheap; a broken main branch is not.
```
**Caveat:** I verified the content against the visible checklist frame, not an indexed source — treat the
"27-page official Anthropic guide" framing as likely-genuine-but-unconfirmed, and the practices above on
their own technical merit rather than on authority.
